# **App Name**: Bhati Study Point

## Core Features:

- Mobile Authentication & Access Control: Secure mobile-based login with role-based navigation for Admins and Students using Firestore for profile verification.
- 70-Seat Grid Visualizer: A responsive, real-time map displaying seat status (Occupied vs. Vacant) for both user roles.
- Membership Pulse Monitor: AI-powered tool to use reasoning to categorize student membership health, identifying users nearing expiration and predicting renewal trends.
- Admin Control Center: Unified dashboard to manage student records, assign/edit seat positions, and perform search queries with instant UI updates.
- Auto-Renewal Engine: System logic to calculate membership duration, remaining days, and automated status alerts based on system time.
- Personal Study Passport: Read-only profile portal for students to monitor their seat assignment, total library capacity, and days until expiry.
- Dual-Mode Theming: Full support for light and dark system settings, maintaining accessibility and high-contrast clarity for long study sessions.

## Style Guidelines:

- Primary color: Scholarly Indigo (#3447B0) used for core navigation and interactive elements.
- Background color: Porcelain Blue (#F5F6FA) for a clean, focus-oriented environment that reduces eye strain.
- Accent: Deep Azure (#209CEE) for highlighting status badges and important library stats.
- Font pairing: 'Space Grotesk' (sans-serif) for high-impact headlines and 'Inter' (sans-serif) for functional, clear data density in tables.
- Mobile-first card-based design with an airy grid layout, ensuring complex administrative tables remain legible on smaller devices.
- Smooth transitions when toggling seat status and micro-interactions on the seat grid to reflect real-time updates.
- Monochrome line icons that shift opacity when items are disabled, ensuring a professional, agency-grade finish.
