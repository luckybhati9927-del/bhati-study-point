# Bhati Study Point - Library Management System

A modern library management system built with Next.js, Firebase, and Genkit AI.

## Features

- **Seat Management**: Interactive 70-seat grid visualization.
- **Student Registry**: Admin panel for managing student profiles and passwords.
- **AI Insights**: Membership health summaries and personalized renewal reminders powered by Genkit.
- **Secure Access**: Role-based access control for Admins and Students.

## Getting Started

1. **Clone the repository**
2. **Install dependencies**: `npm install`
3. **Setup environment variables**: Create a `.env` file with your Firebase credentials.
4. **Run the development server**: `npm run dev`

## How to push to GitHub

To push this project to your new repository `bhati-study-point`, run these commands in your terminal:

1. **Initialize Git**:
   ```bash
   git init
   ```
2. **Add all files**:
   ```bash
   git add .
   ```
3. **Commit changes**:
   ```bash
   git commit -m "Initial commit: Library Management System"
   ```
4. **Link to your GitHub repo**:
   ```bash
   git remote add origin https://github.com/YOUR_GITHUB_USERNAME/bhati-study-point.git
   ```
5. **Push to main**:
   ```bash
   git branch -M main
   git push -u origin main
   ```
